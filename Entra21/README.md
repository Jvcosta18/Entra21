# Entra21 — Portfólio de Atividades

Repositório com todas as atividades desenvolvidas durante o curso **Entra21**, cobrindo fundamentos de **Java** e **Front-End** (HTML, CSS e JavaScript).

---

## 📁 Estrutura do Projeto

```
Entra21/
├── index.html                  ← Página inicial — índice de todas as atividades
├── src/
│   ├── DesvioCondicional/      ← Exercícios Java: if/else, switch (Ex1 a Ex20)
│   └── Array/                  ← Exercícios Java: vetores e arrays (Ex2, Ex3)
└── Front-End/
    ├── cadastro/               ← Sistema de cadastro de usuários (HTML/CSS/JS)
    ├── Cinepolis/              ← Seleção de assentos de cinema
    └── JS/                     ← Exercícios de manipulação do DOM
```

---

## 🖥️ Front-End

### Sistema de Cadastro
Mini-sistema com cadastro e listagem de usuários, utilizando `localStorage` para persistência dos dados.
- `Front-End/cadastro/html/index.html` — formulário de cadastro
- `Front-End/cadastro/html/usuarios.html` — listagem com opção de exclusão

### Cinépolis
Simulação de seleção de assentos de cinema com estados: livre, selecionado e ocupado.
- `Front-End/Cinepolis/index.html`

### Exercícios de DOM (JavaScript)
- `Front-End/JS/atributos.html` — Painel interativo: estilização, tema escuro, contador e lista dinâmica
- `Front-End/JS/creare.html` — Criação e remoção dinâmica de elementos
- `Front-End/JS/index.html` — Validação de formulário

## 🛠️ Tecnologias

- **Java** (JDK 11+) — exercícios de lógica e estrutura de dados
- **HTML5 / CSS3 / JavaScript** — interfaces e interatividade no navegador

---

## 🚀 Como executar

**Front-End:** abra qualquer arquivo `.html` diretamente no navegador, ou use a extensão **Live Server** no VS Code.

**Java:** importe o projeto na sua IDE (IntelliJ, Eclipse ou VS Code com extensão Java) e execute o `main` de cada exercício.
